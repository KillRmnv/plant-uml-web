# componentsandbox.js

## Общее описание

Файл `componentsandbox.js` является частью ядра SCWeb и реализует механизм "песочницы" (sandbox) для компонентов визуализации. Этот файл предоставляет API для компонентов, позволяя им взаимодействовать с системой через безопасный интерфейс.

## Основные компоненты

### 1. SCWeb.core.scAddrsDict

Словарь для хранения sc-адресов, используемый для кэширования разрешённых адресов.

### 2. SCWeb.core.CommandState

Конструктор состояния команды, который хранит информацию о текущей команде:

- `command_addr` - sc-addr команды
- `command_args` - массив аргументов команды
- `format` - формат вывода
- `lang` - язык

### 3. SCWeb.core.ComponentSandbox

Основной класс, предоставляющий "песочницу" для компонентов. Это изолированная среда, через которую компоненты взаимодействуют с системой.

#### Конструктор принимает следующие параметры:

- `command_state` - состояние команды
- `container` - DOM-контейнер
- `window_id` - ID окна
- `addr` - sc-addr просматриваемого/редактируемого элемента
- `content` - содержимое
- `contentStyle` - стиль содержимого
- `is_struct` - флаг, указывающий является ли элемент структурой
- `format_addr` - sc-addr формата
- `canEdit` - флаг разрешения редактирования

#### Свойства экземпляра:

- `command_state` - состояние команды
- `container` - DOM-контейнер компонента
- `container_selector` - jQuery селектор контейнера окна
- `addr` - sc-addr элемента
- `content` - содержимое
- `contentStyle` - стиль содержимого
- `is_struct` - флаг структуры
- `format_addr` - адрес формата
- `is_editor` - флаг режима редактирования
- `keynodes` - словарь ключевых узлов
- `listeners` - массив подписчиков на события
- `childs` - дочерние окна

#### Методы экземпляра:

##### Основные методы:

- `destroy()` - уничтожает песочницу, отписываясь от всех событий
- `createWindowControls()` - создаёт элементы управления окном (в настоящее время пустая функция)

##### Методы для работы с редактированием:

- `canEdit()` - возвращает разрешение на редактирование
- `doDefaultCommand(args)` - выполняет команду по умолчанию с указанными аргументами
- `resolveElementsAddr(parentSelector)` - разрешает sc-addr для всех элементов с атрибутом sc_control_sys_idtf
- `generateWindowContainer(containerId, containerClasses, controlClasses, addr)` - генерирует HTML для нового контейнера окна

##### Методы для работы с ключевыми узлами:

- `getKeynode(sys_idtf)` - возвращает keynode по системному идентификатору
- `getIdentifier(addr, callback)` - получает идентификатор по sc-addr

##### Методы для работы с дочерними окнами:

- `_appendChilds(windows)` - добавляет дочерние окна
- `removeChild()` - удаляет все дочерние окна

##### Методы для работы с результатами:

- `updateResult()` - обновляет результат команды и возвращает переведённый результа
- `createViewersForScLinks(containers_map)` - создаёт просмотрщики для указанных sc-links
- `createViewersForScStructs(containers_map)` - создаёт просмотрщики для указанных sc-structures
- `updateContent(keyElement)` - обновляет содержимое, загружая его с сервера

##### Методы для перевода:

- `getObjectsToTranslate()` - возвращает список объектов для перевода
- `updateTranslation(translation_map)` - применяет перевод к компоненту
- `translate()` - выполняет перевод всех объектов компонента

##### Методы для работы с аргументами:

- `_fireArgumentsChanged()` - вызывает событие изменения аргументов
- `onArgumentAppended(argument, idx)` - обработчик добавления аргумента
- `onArgumentRemoved(argument, idx)` - обработчик удаления аргумента
- `onArgumentCleared()` - обработчик очистки аргументов

##### Методы для работы с окнами:

- `onWindowActiveChanged(is_active)` - обработчик изменения активности окна

##### Методы для работы с данными:

- `onDataAppend(data)` - обработчик добавления данных

## События

Компонент поддерживает следующие события, которые могут быть установлены внешним кодом:

- `eventGetObjectsToTranslate` - событие получения объектов для перевода
- `eventApplyTranslation` - событие применения перевода
- `eventArgumentsUpdate` - событие обновления аргументов
- `eventWindowActiveChanged` - событие изменения активности окна
- `eventStructUpdate` - событие обновления структуры (только для структур)
- `eventDataAppend` - событие добавления данных (только для ссылок)

## Взаимодействие с поисковиками

Для структур создаются поисковики:

- `DefaultSCgSearcher` - поисковик по умолчанию
- `DistanceBasedSCgSearcher` - поисковик на основе расстояния

Для ссылок создаётся:

- `SCCgLinkContentSearcher` - поисковик содержимого ссылок

## Использование

Данный класс используется системой SCWeb для создания безопасной среды выполнения для компонентов визуализации. Компоненты получают экземпляр sandbox при инициализации и используют его API для взаимодействия с системой, не имея прямого доступа к внутренним механизмам.
