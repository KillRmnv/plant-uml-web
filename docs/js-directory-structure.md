# Структура директории js

Директория `external/sc-web/client/js` содержит JavaScript код клиентской части SCWeb - веб-интерфейса для работы с базой знаний OSTIS. Код организован в три основные поддиректории: **Core**, **Ui** и **Utils**.

---

## Директория Core

Модули ядра системы, отвечающие за основную логику работы с SC-сервером, компонентами и интерфейсом команд.

### Файлы:

| Файл | Описание |
|------|----------|
| `namespace.js` | Определяет пространство имён `SCWeb.core` |
| `main.js` | Главный модуль инициализации и управления приложением. Содержит константы режимов редактирования (`SCgEditMode`) и режимов просмотра (`SCgViewMode`), а также основные функции: инициализация приложения, обработка URL-параметров, выполнение команд |
| `server.js` | Модуль взаимодействия с SC-сервером через AJAX. Реализует очередь задач, кэширование идентификаторов, разрешение sc-адресов и системных идентификаторов |
| `translation.js` | Модуль интернационализации и перевода. Управляет сменой языка интерфейса, переводом идентификаторов элементов |
| `eventmanager.js` | Система событий. Позволяет подписываться и публиковать события в приложении |
| `arguments.js` | Управление аргументами команд. Хранит и управляет списком текущих аргументов |
| `componentsandbox.js` | "Песочница" для компонентов визуализации. Предоставляет API для изолированного взаимодействия компонентов с системой |
| `componentmanger.js` | Менеджер компонентов. Регистрирует, инициализирует и создаёт экземпляры компонентов визуализации различных форматов |
| `scg-content-searcher.js` | Поисковики содержимого для визуализации sc-структур. Включает три класса: `DefaultSCgSearcher`, `DistanceBasedSCgSearcher`, `SCgLinkContentSearcher` |
| `debug.js` | Отладочные функции для диагностики работы системы |

## Директория Ui

Модули пользовательского интерфейса, отвечающие за визуальное представление и взаимодействие с пользователем.

### Файлы:

| Файл | Описание |
|------|----------|
| `namespace.js` | Определяет пространство имён `SCWeb.ui` |
| `core.js` | Главный модуль UI. Инициализирует все UI-компоненты, настраивает обработчики событий для sc-элементов (клики, тултипы) |
| `windowmanager.js` | Менеджер окон. Создаёт, управляет и размещает окна просмотра/редактирования компонентов |
| `menu.js` | Меню приложения. Генерирует и обрабатывает команды меню |
| `searchpanel.js` | Панель поиска. Обеспечивает функциональность поиска по базе знаний |
| `langpanel.js` | Панель выбора языка. Позволяет пользователю выбрать язык интерфейса |
| `argumentspanel.js` | Панель аргументов. Управляет отображением и редактированием аргументов команды |
| `taskpanel.js` | Панель задач. Отображает информацию о выполняемых задачах |
| `expertmodepanel.js` | Панель экспертного режима. Предоставляет расширенные функции для опытных пользователей |
| `userpanel.js` | Панель пользователя. Отображает информацию о текущем пользователе |
| `locker.js` | Блокировка интерфейса. Блокирует UI во время выполнения операций |
| `KeyboardHandler.js` | Обработчик клавиатурных событий. Перехватывает и обрабатывает нажатия клавиш |
| `ExpertModeHandler.js` | Обработчик экспертного режима. Управляет переключением режимов работы |
| `OpenComponentHandler.js` | Обработчик открытия компонентов. Обрабатывает события открытия компонентов в окнах |

## Директория Utils

Вспомогательные утилиты и библиотеки для работы с данными.

### Файлы:

| Файл | Описание |
|------|----------|
| `sc_helper.js` | Вспомогательные функции для работы с SC-элементами. Предоставляет методы для получения элементов связок, проверки связей, получения элементов множеств |
| `sc_keynodes.js` | Работа с ключевыми узлами (keynodes). Загружает и кэширует часто используемые узлы базы знаний |
| `sc_types.js` | Определения типов SC-элементов. Содержит константы и функции для работы с типами |
| `sc_link_helper.js` | Вспомогательные функции для работы со sc-ссылками |
| `cache.js` | Реализация кэша в памяти с поддержкой expiration и максимального размера |
| `binary.js` | Работа с бинарными данными |
| `stringview.js` | Оптимизированное представление строк |
| `triples.js` | Работа с тройками (шаблоны поиска в SC-коде) |
| `utils.js` | Общие утилитные функции |
| `cookie.js` | Работа с cookies браузера |
| `fqueue.js` | Очередь функций с приоритетами |

## Архитектура системы

### Поток инициализации:

1. `SCWeb.core.Main.init()` инициализирует:
   - SC-клиент для связи с сервером
   - ScHelper и ScKeynodes
   - TaskPanel
   - Server с начальными данными

2. Вызывается `parseUrl()` для обработки URL-параметров

3. Параллельно инициализируются:
   - `SCWeb.ui.Core` - инициализирует все UI компоненты
   - `SCWeb.core.ComponentManager` - регистрирует компоненты
   - `SCWeb.core.Translation` - загружает переводы

### Взаимодействие компонентов:

```
UI (Ui/)
  │
  ├── WindowManager - управление окнами
  ├── Menu - команды меню
  ├── SearchPanel - поиск
  └── ...

Core (Core/)
  │
  ├── Main - главный контроллер
  ├── Server - связь с сервером
  ├── ComponentManager - управление компонентами
  ├── ComponentSandbox - API компонентов
  ├── Translation - перевод
  ├── EventManager - события
  └── Arguments - аргументы

Utils (Utils/)
  │
  ├── sc_helper - работа с SC-элементами
  ├── sc_keynodes - ключевые узлы
  ├── cache - кэширование
  └── ...
```

### Основные классы:

- **SCWeb.core.Main** - точка входа, управление командами
- **SCWeb.core.Server** - коммуникация с SC-сервером
- **SCWeb.core.ComponentSandbox** - API для компонентов визуализации
- **SCWeb.core.ComponentManager** - регистрация и создание компонентов
- **SCWeb.ui.WindowManager** - управление окнами
- **ScHelper** - вспомогательные функции для работы с базой знаний
- **ScKeynodes** - загрузчик ключевых узлов
